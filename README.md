# 🧪 Element Information Finder

An interactive web application built with Python and Streamlit that functions as a quick-lookup digital periodic table. Users can instantly retrieve atomic properties and interesting facts about various chemical elements through a clean and responsive interface.

---

## 📖 Overview

The **Element Information Finder** is designed as an educational chemistry tool that simplifies access to important atomic data. The application enables users to search for elements using standard chemical symbols and instantly view their atomic details.

This project was developed as part of the **Experiential Learning Project** for the **Computational Chemistry** module in the **B.Tech Computer Science Engineering** program at **Jain University, Kochi**.

---

## 🎯 Academic Context

This project demonstrates the practical implementation of several concepts from chemistry and computer science:

- **Atomic Theory**  
  Organizing and displaying core atomic properties such as atomic number and atomic mass.

- **Periodic Trends**  
  Providing a foundation for understanding element classification and behavior.

- **Data Structures**  
  Using Python dictionaries for efficient storage and retrieval of chemical data.

- **Human-Computer Interaction (HCI)**  
  Designing an intuitive and interactive educational interface.

---

## ✨ Features

- 🔍 **Instant Element Lookup**  
  Search elements using chemical symbols like `H`, `He`, `O`, `Fe`, etc.

- ⚛️ **Real-Time Atomic Data**  
  Displays:
  - Atomic Number
  - Atomic Mass
  - Element Name

- 📚 **Educational Fun Facts**  
  Includes curated facts about each element to enhance experiential learning.

- 🎨 **Interactive User Interface**  
  Clean and responsive dashboard powered by Streamlit.

- ⚡ **Fast Data Retrieval**  
  Efficient backend logic using Python dictionaries.

## 🧠 How It Works

The application uses a Python dictionary to store information about chemical elements.

When a user enters a valid chemical symbol:

1. The input is matched against the internal element database.
2. The corresponding atomic data is retrieved.
3. The interface dynamically displays:
   - Element Name
   - Atomic Number
   - Atomic Mass
   - Fun Fact

This approach ensures fast and efficient lookup performance.
