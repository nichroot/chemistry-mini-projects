# 🧪 Element Information Finder

## Overview
The Element Information Finder is an interactive web application built with Python and Streamlit. It serves as a quick-lookup digital periodic table, allowing users to instantly retrieve atomic properties and interesting facts about various chemical elements. 

This tool was developed as a functional prototype for an Experiential Learning Project (B.Tech Computer Science Engineering at Jain University, Kochi).

## Features
* **Instant Lookup:** Search for elements using their standard chemical symbols (e.g., H, He, O, Fe).
* **Data Retrieval:** Displays core atomic properties including Atomic Number and Atomic Mass.
* **Educational Facts:** Provides a fun, real-world fact for each queried element.
* **Interactive UI:** Built using Streamlit for a clean, responsive, dashboard-like user experience.
